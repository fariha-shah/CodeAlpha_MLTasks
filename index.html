    Documentation & Deployment

    Complete Step-by-Step Developer Guide

    Comprehensive instructions for running locally, deploying live to Netlify with zero configuration, and managing the project on GitHub.

    1

    Run Locally with Any Web Server

    Because the app loads binary neural weights and JSON models via fetch(), start a local HTTP server:

    cd "D:\CodeAlpha-Tasks" python -m http.server 8080

    Then open http://localhost:8080 in your browser.

    2

    Deploying Live on Netlify (100% Free & Instant)

    You have two simple options to host this app live:

    Option A: Drag & Drop to Netlify Drop (Zero Setup)

    1. Navigate to https://app.netlify.com/drop in your browser.
    2. Drag and drop the entire D:\CodeAlpha-Tasks folder into the browser window.
    3. Netlify will instantly deploy the site and provide a free live URL (e.g. https://codealpha-ml-studio.netlify.app)!

    Option B: Connect with GitHub for Continuous Deployment

    1. Sign in to Netlify.
    2. Click "Add new site" ➔ "Import an existing project" ➔ choose GitHub.
    3. Select your repository: fariha-shah/CodeAlpha_Tasks.
    4. Set Publish directory to . (root) and click Deploy Site.
    5. Every time you run git push, Netlify will automatically update your live website!
    3

    Pushing Updates to GitHub

    Run the following Git commands in PowerShell or terminal to push all updates to GitHub:

    cd "D:\CodeAlpha-Tasks" git add . git commit -m "Add unified modern web UI, models, and Netlify deployment setup" git push origin main
    4

    Machine Learning Technical Architecture

    Why client-side browser ML? Traditional deployments require expensive Python cloud servers (EC2, Heroku, Railway) that sleep or crash. By compiling model weights directly into Float32Array SIMD structures and decision trees, this entire studio runs natively at 60 FPS in any device's browser, completely offline-capable, with zero server costs!
