    Documentation & Deployment

    Complete Step-by-Step Developer Guide

    Comprehensive instructions for running locally, deploying live to Netlify in 30 seconds, and synchronizing with GitHub.

    1

    Run Locally with Python Web Server

    Run Python's built-in HTTP server to serve the binary weights and models:

    cd "D:\CodeAlpha-Tasks" python -m http.server 8080

    Then open http://localhost:8080 in your browser.

    2

    Deploying Live to Netlify (100% Free & Instant)

    You have two simple options to host this app live:

    Option A: Drag & Drop to Netlify Drop (30 Seconds)

    1. Open https://app.netlify.com/drop in your browser.
    2. Drag and drop the entire D:\CodeAlpha-Tasks folder into the browser window.
    3. Netlify will instantly deploy your website and provide a free live URL (e.g. https://codealpha-ml-studio.netlify.app)!

    Option B: Connect with GitHub for Continuous Deployment

    1. Sign in to Netlify.
    2. Click "Add new site" ➔ "Import an existing project" ➔ choose GitHub.
    3. Select your repository: fariha-shah/CodeAlpha_Tasks.
    4. Set Publish directory to . (root) and click Deploy Site.
    3

    Pushing Updates to GitHub

    Run the following Git commands in PowerShell to synchronize updates:

    cd "D:\CodeAlpha-Tasks" git add . git commit -m "Update bespoke UI theme and accurate model predictions" git push origin main
    Live Deployment

    How to Go Live on Netlify

    Your project is already configured with netlify.toml, binary MIME headers, and 100% client-side inference.

    1-Click Drag & Drop: Open app.netlify.com/drop and drag the D:\CodeAlpha-Tasks folder into the browser.
    Sync with GitHub: 
    git add .
git commit -m "Deploy latest CodeAlpha ML Studio"
